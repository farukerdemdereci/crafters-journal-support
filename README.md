# Crafter's Journal Website

Static GitHub Pages website for Crafter's Journal.

## Before publishing

1. Put your logo file at:
   `assets/logo.png`

2. Replace every occurrence of:
   `farukerdemdereci@gmail.com`
   with your real support email address.

3. Review `privacy.html` and make sure it exactly matches the app's actual data practices.

## GitHub Pages

1. Create a new public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

GitHub will give you a public website URL. You can later connect a custom domain.
